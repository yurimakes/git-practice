# Git Practice

오픈소스SW 7주차 Git 실습용 저장소입니다.

## 실습 목표

- 로컬 저장소를 만들고 파일을 관리한다.
- `git add`와 `git commit`의 차이를 이해한다.
- `.gitignore`로 불필요한 파일을 제외한다.
- 로컬에서 만든 커밋을 GitHub에 올린다.

## 파일 설명

- `main.py`: 단어 목록을 출력하는 간단한 Python 코드
- `words.txt`: 프로그램에서 읽어 올 단어 목록
- `git_commands.md`: 수업에서 다룬 Git 명령어 정리
- `git_notes.md`: Git의 세 가지 상태와 주의할 점 정리
- `practice_log.md`: 실습 순서 및 간단한 회고
- `.gitignore`: Git에서 추적하지 않을 파일 목록

## 실행

Python이 설치된 상태라면 다음 명령어로 실행할 수 있습니다.

```bash
python main.py
```
